# AI Job Reader

AI 분야 취업 준비생을 위한 채용 공고 자동 수집 웹사이트입니다.

## 주요 기능

- 잡코리아, 사람인, 자소설닷컴, 직행 등 채용 플랫폼의 공개 검색 페이지 참고
- 잡코리아, 사람인은 여러 AI 키워드로 반복 검색해 더 많은 공고 수집
- 회사 자체 채용 사이트와 주요 테크 기업 채용관 링크 제공
- HD현대 연구직 채용처럼 포털 수집에서 누락될 수 있는 핵심 공식 공고 큐레이션 반영
- 원티드, 점핏, 프로그래머스 커리어, 랠릿, 로켓펀치, LinkedIn 등 추가 탐색 채널 제공
- AI, 머신러닝, 딥러닝, LLM, NLP, 컴퓨터비전, MLOps, 데이터 직무 중심 필터링
- 대기업, 중견기업, 중소기업, 스타트업 기업 규모 필터
- Vision AI, LLM, Physical AI, Robotics, Manufacturing AI 등 세부 키워드 필터
- 경력, 학력, 근무지, 고용형태, 마감 정보를 공고 카드에서 요약
- 공고 클릭 시 원문 지원 페이지로 이동
- 첫 화면 브랜드 인트로, 스크롤 전환 레이더, 라이브 티커 모션
- 공고 목록은 처음 20개 표시 후 더보기로 20개씩 추가 노출
- GitHub Actions로 매일 `public/jobs.json` 자동 갱신
- GitHub Pages 정적 배포 지원

## 로컬 실행

```bash
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 열면 됩니다.

## 데이터 갱신

```bash
npm run collect
```

수집기는 각 사이트의 공개 HTML 구조에 의존합니다. 사이트 구조가 바뀌거나 접근이 제한되면 해당 출처는 검색 페이지 링크로 대체되고, 다른 출처의 수집은 계속 진행됩니다.

## 디자인

폰트는 눈누의 나눔바른고딕 웹폰트를 적용했습니다. 첫 화면은 어두운 브랜드 인트로, 스크롤 구간은 다채로운 레이더/티커 인터랙션, 공고 영역은 밝은 탐색 UI로 구성했습니다.
